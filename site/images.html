An NVIDIA GPU answers on the bus as vendor 10de. No line here means the first image.

lspci -d 10de:

The closed-driver base carries its own kernel, and each flavour gets its kernel modules built against the kernel of its own base. ujust verify-host catches a host on the wrong flavour.

Tags

TagWhat it points at
:stablethe tag a host follows; it moves only onto a release the gate has verified
:44.<yyyymmdd>one release, never moved; the first number is the Fedora version of the base
:stagingwhat the last release run pushed before its gate, re-pointed by every run

Every dated tag is on the releases page with the digest of each image. A host pinned to one never updates, so to try a release and come back:

ujust migrate apply 44.<yyyymmdd>    # the dated tag
ujust migrate apply                  # back to stable

Updates and rollback

After the migration the host updates the Bazzite way: uupd on its timer, or by hand. The previous deployment stays on disk and boots from the boot menu.

sudo bootc upgrade          # fetch and stage the next :stable, reboot to use it
rpm-ostree rollback         # make the previous deployment the default again
systemctl reboot

Every pull is checked against the signing policy inside the booted image, so an image without a valid signature is refused before staging (verify).
