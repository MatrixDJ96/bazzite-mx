Three images, one recipe

Only the base image differs. Pick the one your graphics stack needs.

  • ghcr.io/matrixdj96/bazzite-mx:stableon ghcr.io/ublue-os/bazzite:stableAMD or Intel graphics
  • ghcr.io/matrixdj96/bazzite-mx-nvidia-open:stableon ghcr.io/ublue-os/bazzite-nvidia-open:stableNVIDIA, open kernel modules (Turing and newer)
  • ghcr.io/matrixdj96/bazzite-mx-nvidia:stableon ghcr.io/ublue-os/bazzite-nvidia:stableNVIDIA, closed driver

Follow :stable. The images page has the other tags, the update command and the rollback.

Start here

Five commands from a Bazzite host. The first rebase is unsigned: stock Bazzite trusts nothing under ghcr.io/matrixdj96. ujust migrate moves the host onto the signed origin, asking before every change.

sudo rpm-ostree rebase ostree-unverified-registry:ghcr.io/matrixdj96/bazzite-mx:stable
systemctl reboot
ujust migrate apply
systemctl reboot
ujust verify-host

On an NVIDIA machine name bazzite-mx-nvidia-open instead, or bazzite-mx-nvidia for the closed driver. Step by step: install.

Verify an image

Every published image is signed by digest with cosign.pub, the key the image itself trusts, and attested by the workflow run that built it. The verify page has both commands, the SBOM, the release gate and the checks a migrated host makes on its own.

A single-maintainer image, built in the open, not affiliated with Bazzite or Universal Blue. Rebase at your own risk. Source under Apache-2.0: MatrixDJ96/bazzite-mx.
