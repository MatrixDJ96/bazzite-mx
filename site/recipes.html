Recipes

Nine ujust recipes come from this image, three of them in place of a Bazzite recipe of the same name. Each answers ujust <name> help, and none runs as root: they call sudo where a step needs it.

Added by the image

ujust migrate

  • plan
  • apply
  • apply <tag>
  • help

Brings this host to the state the image expects, one confirmation per change but step 2 (backups, pin, timer stop), the reboot left to you. plan is read-only and the default; the tag defaults to stable. Step by step: install.

ujust verify-host

  • help

Checks the host against what the image expects and prints one line per check, exiting 1 on any FAIL:. Every failing line names its fix or why the check could not run (install).

ujust setup-ntfsplus

  • status
  • enable
  • disable
  • help

Uses the NTFSPLUS driver for this host's NTFS volumes. enable proves the driver on a loop image, switches the fstab rows from ntfs3 to ntfs and remounts what is not busy; disable is the reverse. Every ntfs row without an errors= option gains errors=remount-ro, and the volumes the file manager mounts take it from the image, so a dirty volume, or one Windows hibernated on, mounts read-only; fast startup can leave a volume with neither sign, so turn it off in Windows. No mask is written: a row without umask, fmask or dmask goes from 0755 under ntfs3 to 0777 under NTFSPLUS, writable by every account. The module is unsigned, so Secure Boot has to be off.

ujust setup-msi

  • status
  • enable
  • disable
  • help

Only on an MSI system. enable loads msi-ec and acpi_ec now and at boot and installs MControlCenter; disable undoes both. The modules are unsigned, so Secure Boot has to be off.

ujust setup-panels

  • help

Runs the image's Plasma panel script again in the running session, for a login that had one screen or a screen added later. Every screen without a panel gets one.

ujust setup-dev

  • status
  • install
  • help

install seeds ~/.config/mise/config.toml from the image's default when you have none, then runs mise install for this user. A project's own mise.toml wins over the global config.

In place of Bazzite's

ujust setup-virtualization

  • status
  • kvmfr
  • help

Bazzite's version installs the virt-manager Flatpak, enables the monolithic libvirt daemon and adds kernel arguments. All of that is in the image here, so status reports what the host has and kvmfr sets up the module for Looking Glass.

ujust setup-sunshine

  • status
  • enable
  • disable
  • portal
  • virtual-monitor
  • help

Bazzite's version installs a Flatpak or a Homebrew build per host. Sunshine is an RPM of the image here, so enable and disable switch the user unit; enable also limits the portal to this PC unless the user set origin_web_ui_allowed, and asks for the portal's credentials before the first start; the Sunshine entry of the menu runs enable. portal opens the management page and virtual-monitor adds a KWin virtual display per stream.

ujust install-jetbrains-toolbox

  • install
  • status
  • latest
  • help

Bazzite's version installs a Homebrew cask. This one downloads the newest Toolbox build from JetBrains' release feed, verifies its sha256 against the feed, unpacks it under ~/.local/share/JetBrains/ToolboxApp and starts it once.

What each recipe does under the hood, with its sources, is in docs/divergences.md.
